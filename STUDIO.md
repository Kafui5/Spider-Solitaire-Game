# Green Midori — Studio Identity

*Established 2026. Publisher of Silk Spider Solitaire.*

---

## Studio Name

### Options Considered

| Name | Rationale |
|------|-----------|
| **Green Midori Games** | "Midori" = green in Japanese. Double-green is intentional. Memorable, unique. |
| Silk Loom Studio | Ties to the weaving/textile theme but limits future non-card games |
| Quiet Loom Games | Evocative but potentially too niche |
| Midori Play | Clean but generic; lacks warmth |

### Current Choice: **Green Midori**

- Package: `com.greenmidori.silkspider`
- Publisher name on Google Play: **Green Midori**
- Support email: support@greenmidori.com
- Website: greenmidori.com

The name works for a solo developer or small studio. It doesn't pigeonhole the brand into a single game genre.

---

## Brand Values

1. **Calm, focused gaming experiences** — No timers pressuring you. No energy mechanics. No FOMO manipulation.
2. **No ads, no manipulation** — Revenue through fair one-time purchases and honest cosmetics.
3. **Beautiful original artwork** — Every visual element is crafted with care. Inspired by textile arts, not stock assets.
4. **Respectful of player time and intelligence** — No tutorials that take 20 minutes. No artificial gates. Trust the player.
5. **Accessible to all** — Color-blind friendly. Screen-reader compatible where possible. Generous free tier.

## Visual Identity

### Primary Mark

**Gold Spade** — derived from the app icon. A stylized spade shape with Kente geometric patterns within it. Used as:
- App icon centerpiece
- Favicon
- Watermark on promotional materials
- Loading indicator

### Color Palette

| Role | Color | Hex |
|------|-------|-----|
| Primary Background | Dark Green | `#071D18` |
| Surface | Felt Green | `#0D3B2E` |
| Accent | Gold | `#E6B95C` |
| Accent Light | Soft Gold | `#F3D58F` |
| Text Primary | Cream | `#FFF8E9` |
| Text Secondary | Muted Sage | `#AFC8BE` |
| Warm Accent | Clay | `#C96842` |
| Ink | Deep Black-Green | `#07130F` |

### Brand Motif

**Kente Color Strip** — A horizontal band of repeating geometric patterns in gold, clay, and indigo on dark green. Used as:
- Header/footer decoration on web pages
- Divider element in marketing materials
- Store listing feature graphic border
- Card back design foundation

### Typography

- Headlines: Bold, tracked-out uppercase (2px letter-spacing)
- Body: Clean, readable sans-serif
- In-app: System font for performance, styled with weight and color

### Design Principles

1. **Dark-first** — All surfaces are dark green. Light elements are reserved for text and accents.
2. **Gold means action** — Gold is used for interactive elements, CTAs, and highlights.
3. **Breathing room** — Generous spacing. Cards need room to breathe.
4. **Subtle texture** — Not flat, not noisy. Think polished wood and fine fabric.
