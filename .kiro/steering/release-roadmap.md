# Release Roadmap — Silk Spider Solitaire

## Version 1.0 — Launch (Target: September 2026)

### Must ship:
- [x] Excellent drag-and-drop + tap-to-move
- [x] 1-suit, 2-suit, 4-suit modes
- [x] Undo, hints, automatic saving
- [x] Daily Loom with sharing
- [x] Personal records and basic statistics
- [x] ~6 initial achievements
- [x] Free Weaver / Full Weaver split
- [x] Purchase restoration
- [x] 3 free + several premium card backs
- [x] Settings (sound, haptics, card size, accessibility)
- [x] Onboarding tutorial
- [x] Auto-complete
- [x] Privacy policy and support info
- [ ] Real sound effects (6 audio files)
- [ ] App icon PNG exports
- [ ] 8 Play Store screenshots
- [ ] Feature graphic
- [ ] Final testing on physical devices

### Explicitly deferred:
- Cloud sync / accounts
- Global leaderboards
- Real-time multiplayer
- Push notifications
- Referral rewards
- AI opponents

## Version 1.1 — First Content Update (2-3 weeks post-launch)

- 2 new card backs (seasonal)
- Monthly event system (themed daily challenges for the month)
- Journey Mode (Chapter 1 only — 20 levels)
- Bug fixes from launch feedback
- Respond to all reviews

## Version 1.2 — Engagement Update (5-6 weeks post-launch)

- Journey Mode Chapters 2-3
- Loom Gallery artwork #1 completable
- 3 additional achievements
- Supporter Packs available
- Share result improvements (image generation)

## Version 1.3 — Quality of Life (8-10 weeks post-launch)

- Undo animation
- Android widget (daily challenge status)
- Landscape tablet optimization
- Localization: Spanish, French, Portuguese
- Performance optimization for budget phones

## Version 1.4+ — Growth Phase

- Journey Mode Chapters 4-5
- Remaining Loom Gallery artworks
- Weekly challenges
- Cosmetic packs release
- Localization: German, Japanese
- Seasonal events (holiday themes)
- Consider iOS port if Android proves concept

## Long-term (6-12 months)

- Evaluate: Is retention strong enough to invest in a second title?
- If yes: Begin "Silk FreeCell" or "Silk Klondike" design
- Build studio brand across titles
- Never compromise the core principles for growth
